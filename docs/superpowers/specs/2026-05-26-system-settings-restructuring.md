# 系统配置模块重构需求文档

## 1. 背景与目标

### 现状问题
- 用户管理嵌套在系统配置子菜单中，不符合权限管理逻辑
- 系统配置未分类，参数混杂在一起
- 配置参数存储在 App.config 中，不够灵活
- 通讯设置和设备控制参数无法同步到 VisionMaster 算法平台

### 重构目标
1. 将用户管理独立为一级导航菜单
2. 系统配置按功能分为4个独立子模块
3. 配置参数独立存储（JSON文件）
4. 关键参数可同步到 VisionMaster 算法平台

## 3. 功能需求

### 3.1 用户权限模块

#### 功能列表
- 用户列表展示
- 添加用户
- 编辑用户（基本信息、角色）
- 启用/停用用户
- 解锁用户（密码错误超过次数后）
- 删除用户

#### 角色定义

| 角色 | 权限说明 |
|------|---------|
| 管理员 | 全部菜单可访问 |
| 主管 | 全部菜单可访问 |
| 操作员 | 无「用户权限」菜单访问权限、无「任务审批」功能权限 |

#### 用户属性
- 用户名（唯一）
- 真实姓名
- 密码
- 角色（管理员/主管/操作员）
- 状态（启用/停用）
- 锁定状态（正常/锁定）
- 创建时间
- 最后登录时间

### 3.2 系统配置 - 通讯设置

#### 相机设置
| 参数 | 类型 | 说明 |
|------|------|------|
| 相机IP | string | 相机 IP 地址 |
| 相机端口 | int | 相机端口号 |

#### PLC设置
| 参数 | 类型 | 说明 |
|------|------|------|
| PLC IP | string | PLC IP 地址 |
| PLC端口 | int | PLC 端口号 |
| PLC类型 | enum | Mitsubishi（三菱）/ Siemens（西门子）/ Omron（欧姆龙） |
| 波特率 | int | 通讯波特率，如 9600, 115200 |

### 3.3 系统配置 - VisionMaster设置

| 参数 | 类型 | 说明 |
|------|------|------|
| VM安装路径 | string | VisionMaster 安装目录路径 |

### 3.4 系统配置 - 系统设置

#### 日志相关
| 参数 | 类型 | 说明 |
|------|------|------|
| 日志保存方式 | enum | 按日期分目录（Log/YYYY-MM-DD/） |
| 日志保存天数 | int | 超过天数自动清理，0=不清理 |
| 日志导出目录 | string | 日志导出目标路径 |
| 是否自动清理日志 | bool | true=启用自动清理 |

#### 工厂信息
| 参数 | 类型 | 说明 |
|------|------|------|
| 工厂编号 | string | 如 F001 |
| 生产线号 | string | 如 L001 |

#### 数据备份
| 参数 | 类型 | 说明 |
|------|------|------|
| 数据库备份根目录 | string | 数据库备份存储路径 |

#### 图片管理
| 参数 | 类型 | 说明 |
|------|------|------|
| 图片保留个数 | int | 保留的最新图片数量，0=保留全部 |
| 是否自动清图 | bool | true=超过数量自动清理 |

### 3.5 系统配置 - 设备控制设置

#### 光源控制
| 参数 | 类型 | 说明 |
|------|------|------|
| 光源类型 | string | 如 LED、Halogen |

#### 拍照时序
| 参数 | 类型 | 说明 |
|------|------|------|
| 拍照延时(ms) | int | 触发后延迟拍照的毫秒数 |
| 拍照反馈超时(ms) | int | 等待拍照完成的超时时间 |

#### 剔除控制
| 参数 | 类型 | 说明 |
|------|------|------|
| 剔除延时(ms) | int | 检测完成后到执行剔除的延迟 |
| 剔除时长(ms) | int | 剔除信号持续时间 |
| 连续剔除触发停线 | int | 连续多少个NG后触发停线，0=不启用 |

### 3.6 参数同步功能

#### 同步范围
以下参数可通过「同步到VM」按钮同步到 VisionMaster 算法平台：
- 通讯设置：相机IP、相机端口、PLC IP、PLC端口、PLC类型、波特率
- 设备控制设置：光源类型、拍照延时、拍照反馈超时、剔除延时、剔除时长、连续剔除触发停线

#### 同步方式
- 使用 VisionMaster SDK 的 `ImvsSdkPFSync` 模块
- 调用 `SetGlobalVarValue` 写入全局变量
- 算法平台通过读取全局变量获取配置

## 6. 模块边界（执行边界）

为确保不影响已调试完成的功能，本次重构按以下模块边界分阶段实施：

### 阶段边界
1. **不修改** 已完成的检测模块 (DetectionView)
2. **不修改** 已完成的仪表盘模块 (DashboardView)
3. **不修改** 已完成的日志模块 (LogsView)
4. **不修改** TabManager 核心逻辑（仅扩展注册）
5. **新建** Settings 子目录，所有新文件放入子目录
6. **新建** Config 目录存储 JSON 配置

### 文件命名约定
- 现有 SettingsView → 改造为 SettingsShellView
- 新建 Settings 子视图: CommunicationSettingsView, VmSettingsView, SystemSettingsView, DeviceControlSettingsView
- 用户权限: UserManagementView
