# 检测执行页面布局重新设计

## 一、背景与目的

重新设计检测执行页面（DetectionView）的布局，将任务选择和统计数据提升到顶部，优化空间利用效率。

## 二、新布局结构

```
┌─────────────────────────────────────────────────────────┐
│  Task Selection (40%)      │  Statistics (60%)          │ ← Row 0: 5%
│  ┌────────────────────────┐│  ┌─────┬─────┬─────┬─────┐│
│  │ 任务下拉 │ 产品名称    ││  │ OK  │ NG  │ Pass│Total││
│  ├────────────────────────┤│  │ 0   │  0  │ --  │  0  ││
│  │ 批号 │ 生产日期 │ 有效期││  └─────┴─────┴─────┴─────┘│
│  └────────────────────────┘│                             │
├─────────────────────────────────────────────────────────┤
│                              │                            │
│  VisionMaster Display (65%) │  Detection Results (35%)  │ ← Row 1: 75%
│                              │  ┌─────────────────────┐  │
│  ┌─────────────────────┐   │  │   OK / NG (大字)    │  │ ← 当前结果（绿/红）
│  │   VmRenderHost      │   │  ├─────────────────────┤  │
│  │   (VM 显示区域)      │   │  │   检测历史列表       │  │ ← 最近 100 条
│  └─────────────────────┘   │  │   (时间/批号/结果)   │  │
│                            │  └─────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│  Operation Panel (60%)       │  Operation Logs (40%)    │ ← Row 2: 20%
│  ┌───────┬───────┬───────┐ │  ├─ VM 操作日志         │
│  │ 方案  │ 三期   │ 工序  │ │  │  - 方案加载记录       │
│  │ 操作  │ 参数   │ 选择  │ │  │  - 参数设置记录       │
│  │+路径  │        │       │ │  │  - 运行状态记录       │
│  └───────┴───────┴───────┘ │  └─ 可滚动日志列表       │
└─────────────────────────────────────────────────────────┘
```

### 三行高度比例

| Row | 区域 | 高度比例 |
|-----|------|----------|
| Row 0 | Task Selection + Statistics | 5% |
| Row 1 | VM Display + Detection Results | 75% |
| Row 2 | Operation Panel + Operation Logs | 20% |

### 左右列比例

| 区域 | 列比例 |
|------|--------|
| Task Selection | 40% |
| Statistics | 60% |
| VM Display | 65% |
| Detection Results | 35% |
| Operation Panel | 60% |
| Operation Logs | 40% |

## 三、Task Selection 区域详细布局

```
┌────────────────────────────────┐
│ ┌──────────────┐ ┌────────────┐ │
│ │ 任务下拉    │ │ 产品名称   │ │ ← 同一行
│ └──────────────┘ └────────────┘ │
│ ┌────────┐┌────────┐┌────────┐ │
│ │ 批号   ││ 生产日期│ │ 有效期 │ │ ← 同一行
│ └────────┘└────────┘└────────┘ │
└────────────────────────────────┘
```

**显示字段：**
- 任务名称（ComboBox 下拉选择）
- 产品名称（只读显示）
- 批号（只读显示）
- 生产日期（只读显示）
- 有效期至（只读显示）

## 四、Statistics 区域详细布局

```
┌─────┬─────┬─────┬─────┐
│ OK  │ NG  │ Pass│Total│
│  0  │  0  │ --  │  0  │
└─────┴─────┴─────┴─────┘
```

**统计指标：**
- OK 数量
- NG 数量
- Pass Rate（合格率百分比）
- Total 总数

## 五、Operation Panel 区域详细布局（60%宽度，三等分）

```
┌─────────────┬─────────────┬─────────────┐
│   方案操作   │   三期参数   │   工序选择   │
│  ├选择方案   │  ├ToVM      │  ├ComboBox   │
│  ├加载方案   │  ├FromVM    │  ├单次运行   │
│  └方案路径   │  └BN/Mfg/EXP│  └连续运行   │
└─────────────┴─────────────┴─────────────┘
```

**第一块（方案操作+路径）：**
- 选择方案 按钮
- 加载方案 按钮
- 方案路径 TextBlock 显示

**第二块（三期参数）：**
- 三期ToVM 按钮
- 三期FromVM 按钮
- BN/Mfg/EXP 变量显示

**第三块（工序选择）：**
- 工序选择 ComboBox
- 单次运行 按钮
- 连续运行 按钮

## 六、Detection Results 区域详细布局（35%宽度）

```
┌─────────────────────────┐
│   OK / NG (大字)        │ ← 当前结果，绿/红色背景
├─────────────────────────┤
│   检测历史列表           │ ← 最近 100 条记录
│   (时间/批号/结果)      │
└─────────────────────────┘
```

**布局：**
- 当前结果大字显示在最上方（OK 绿色，NG 红色）
- 检测历史列表在下方（时间、批号、结果）

## 七、操作 Logs 区域详细布局（40%宽度）

```
├─ VM 操作日志
│  - 方案加载记录
│  - 参数设置记录
│  - 运行状态记录
└─ 可滚动日志列表
```
